# React Registration and Login

A simple React + Vite project for practicing forms and `useState`.

## Features
- Registration form with name, email, and password.
- Displays the registered details below the registration form.
- Login form checks the entered email and password against the registered details.
- Shows a success message when credentials match, otherwise shows an error.
- Responsive layout.

## Run the project

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Extract this ZIP file and open the project folder in VS Code.
3. Open the terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Note
This is an educational front-end demo. Data is kept only in React state, so it is cleared on refresh. The password is displayed because the exercise requests displaying all entered details. Do not use this approach for a real application; real systems should never display passwords and must use secure server-side authentication and password hashing.
